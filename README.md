# Visualização de Dados

Projetos de **data visualization** para comunicar padrões, tendências e indicadores de forma clara.

## Técnicas
- Gráficos comparativos
- Séries temporais
- Distribuições
- Correlações
- KPIs e indicadores
- Storytelling com dados

## Tecnologias
Python • Pandas • Matplotlib • Plotly

## Princípios
Clareza • contexto • consistência • acessibilidade • foco na pergunta de negócio
